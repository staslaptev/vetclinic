# ВетЭксперт — лендинг ветклиники, Энгельс

Одностраничный сайт на чистом HTML, CSS и JavaScript, без сборки.

## Запуск
Откройте `index.html` в браузере. Для живой карты лучше запустить любой локальный сервер, например:

```
npx serve .
```

## Структура
- `index.html` — разметка всех блоков
- `css/tokens.css` — цвета, шрифт, размеры; `css/main.css` — стили
- `js/config.js` — контакты клиники, ссылки на мессенджеры, почта для заявок
- `js/main.js` — поведение страницы: меню, прокрутка, форма, карусели, карта
- `js/anim.js` — анимации (GSAP + ScrollTrigger с cdnjs)
- `js/hearts.js` — надпись из сердечек в подвале
- `img/` — фото (сжатые .jpg / .webp)
- `DESIGN-SYSTEM.md` — дизайн-система, `PLAN.md` — план и статус, `PROMPTS.md` — промпты для изображений
- `tools/build-preview.mjs` — сборка одного файла для превью, `tools/cutout.py` — вырезка фона
